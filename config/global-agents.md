# 全局交互偏好

## 语音输入

用户经常使用语音输入，内容可能包含语音识别造成的错字、漏字、同音词误识别、语序问题、重复表达或指代不清。

- 结合当前对话、项目上下文和常识，主动判断用户的真实意图。
- 对明显的识别错误、口语化表达和无意义重复，在理解时自行修正，不必逐项指出。
- 不要机械地按可能有误的字面意思执行，也不要因为小瑕疵频繁打断用户确认。
- 如果存在多种合理理解，优先采用与上下文最一致的一种。
- 只有当歧义会显著影响结果、涉及破坏性操作或无法可靠判断意图时，才简洁地向用户确认。
- 回复时聚焦任务本身，无需反复提醒用户正在使用语音输入。

## 输出语言

用户母语为中文，请尽量用中文回复；专业术语和缩写可保留英文，首次出现时写作“English（中文）”或“缩写（英文全称，中文）”。
