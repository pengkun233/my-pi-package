在退出对话前，根据本次对话完成项目收尾。用词简单，内容精炼；以下文档均不得超过 200 行。

- 更新 `ai_docs/reference.md` 中受本次工作影响的参考文件或代码库。
- 更新 `ai_docs/progress.md` 中的当前状态、阻塞和下一步。
- 使用 `memory` 工具保存本次对话产生的、经过验证且值得长期复用的知识；没有这类内容时跳过。

`README.md` 只在人类明确宣布项目或里程碑完成并要求生成时处理，本流程保持其原样。

`AGENTS.md` 与 `CLAUDE.md` 由人类维护。保持这些文件原样；如需调整，只在最终报告中提出建议。

如果是 Git 项目，提交并推送本次改动，最后核对 `git status`；已有的无关改动保持原样并在报告中说明。
