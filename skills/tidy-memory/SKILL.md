# 整理项目记忆与开发经验

整理当前项目的 project memory 和 `ai_docs/engineering.md`（如存在）

`AGENTS.md` 与 `CLAUDE.md` 由人类维护。保持这些文件原样；发现错误、过期内容或缺失规则时，只在最终报告中提出建议。

## 盘点

读取范围内的完整 memory 和 `engineering.md`。每个 topic 和经验条目都须有裁决：**保留、合并、修正、删除或待查**，并有事实依据。

盘点完成标准：全部内容都有裁决和依据。

## 整理

Memory 只保存经验证、长期有效、可跨会话复用且不容易直接从仓库查到的知识。

合并两处语义重复的内容，保全独有信息，按适用范围选择保留位置。冲突以核实证据为准，不预设哪一方更权威；删除已失效、被取代、仅描述临时任务或没有独有价值的内容。证据不足的内容保持原状并归入待查。

以磁盘上的最新索引为准；`upsert` 前读取完整 topic；合并时先保存完整内容，再删除重复项。保留用户原有工作区改动。敏感值只执行清理，不在修改记录或报告中复述。

整理完成标准：有效的独有信息全部保留；范围内不再存在已知的重复、矛盾、错误或过期内容。

## 验收

重新索引并核对 memory，复查 `engineering.md` 及各项裁决的证据。

最终报告简述两处的整理结果，并单列待查项及对人类维护文档的修改建议。
