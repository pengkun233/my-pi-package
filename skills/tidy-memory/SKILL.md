# 整理项目长期记忆

默认只整理当前项目的 project memory；global memory 仅在用户明确要求时纳入。代码、配置、测试、Git 历史和项目文档都是核实事实的只读证据。

`AGENTS.md` 与 `CLAUDE.md` 由人类维护。保持这些文件原样；发现错误、过期内容或缺失规则时，只在最终报告中提出建议。

## 盘点

读取范围内磁盘上的完整 memory。每个 topic 都必须得到一个裁决：**保留、合并、修正、删除或待查**，并有事实依据。

盘点完成标准：全部 topic 都已有裁决、依据和明确的权威归属。

## 整理

Memory 只保存经验证、长期有效、可跨会话复用且不容易直接从仓库查到的知识。

合并语义重复的 topic，并保全各自独有信息。按只读事实源修正冲突内容；删除已失效、被取代、仅描述临时任务或没有独有价值的内容。证据不足的内容保持原状并归入待查。

以磁盘上的最新索引为准；`upsert` 前读取完整 topic；合并时先写入完整 canonical topic，再删除已被吸收的 topic。保留用户原有工作区改动。敏感值只执行清理，不在修改记录或报告中复述。

整理完成标准：有效的独有信息全部保留；范围内不再存在已知的重复、矛盾、错误或过期内容。

## 验收

重新索引并核对 memory，复查每项裁决及其证据。

最终报告列出 memory 的合并、修正和删除结果，并单列待查项及对人类维护文档的修改建议。
